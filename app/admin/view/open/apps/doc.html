接口1：获取数据

通过api get查询哪个账号哪一天有多少数据量和数据内容列表 
GET {:request()->domain()}/open/index/id/{$row['id']}/token/{$row['token']}

请求参数

参数名称 类型 必须 描述
account string 是 查询哪个账号负责人下的数据
create_time string 是 查询哪一天的数据,格式类似：2024-02-18
page string 否 查询哪一页的数据,默认返回第一页，每一页返回10条，根据客户信息创建时间降序排列

返回参数

名称 类型 说明
code int 状态 0 获取失败 1 获取成功
msg string 返回提示信息
count int 查询结果总数据量
data json 查询结果数据集合(详见如下data数据集说明，返回的是列表展示字段数据集合)
