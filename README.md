# 符号象CRM客户关系管理系统

> 版本：v5.1.2 | 构建时间：2026-08-05 | 框架：ThinkPHP 8

**符号象CRM** —— 可定制、可扩展的企业级客户关系管理系统。一套系统,全端触达,全行业适用。

- 🎯 **行业无界**:内置**自定义字段引擎**,无需写代码即可为不同行业量身定制业务模型,制造、贸易、服务、教育……皆可开箱即用
- 🧩 **无限扩展**:插件化架构支持新增插件,为构建全平台功能提供持续支撑
- 📱 **全端覆盖**:PC 后台管理端 + 移动端(uni-app H5/小程序/App)
- 🔒 **安全可控**:RBAC 三级权限 + 数据范围管控,客户资产尽在掌握

覆盖客户、商机、合同、回款全生命周期管理,助力销售团队高效跟进、管理层科学决策。

## 项目简介

符号象CRM 基于 **ThinkPHP 8 多应用模式** 开发，通过不同入口文件访问不同应用：

| 入口文件 | 应用 | 用途 |
|----------|------|------|
| `admin.php` | admin | 后台管理端（Layui 渲染） |
| `api.php` | api | 移动端 JSON 接口（JWT 认证） |
| `index.php` | index | 前台首页 |
| `install.php` | install | 系统安装向导 |

### 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 后端框架 | ThinkPHP 8 | 多应用模式，PHP >= 8.0 |
| ORM | think-orm 3.0 | 模型关联、字段缓存 |
| 数据库 | MySQL（utf8mb4） | 表前缀 `ymwl_` |
| 后台前端 | Layui + RequireJS | 模块化 JS 加载 |
| 移动端前端 | uni-app + uView UI | H5/微信小程序/App，见 [crm_uniapp/README.md](crm_uniapp/README.md) |
| 认证 | Session（后台）/ JWT（API） | firebase/php-jwt |
| Excel | PhpSpreadsheet + OpenSpout | 导入导出 |
| 邮件 | PHPMailer | SMTP 发送 |
| 微信 | wechat-developer | 公众号集成 |
| 安全 | voku/anti-xss | XSS 过滤 |
| 插件系统 | ymwl/think8-addons | 热插拔扩展 |

## 功能特性

- **客户管理**：客户 CRUD、转移、共享、导入导出、查重
- **公海管理**：公海池、领取、回收机制
- **线索管理**：线索录入、转化客户、公共线索池
- **商机管理**：商机阶段推进、关联客户/联系人
- **合同订单**：合同审批、续费、订单管理
- **回款管理**：回款记录、回款计划、到期提醒
- **跟进记录**：客户/商机/线索跟进
- **审批流程**：待办审批、审批日志
- **业绩分析**：业绩目标、排行榜、数据看板
- **自定义字段**：`system_field` 表驱动的动态字段系统，无需改代码即可扩展业务字段
- **RBAC 权限**：权限节点 + 角色组 + 数据范围（我的/下属/全部）三级管控
- **应用集成**：邮件发送（SMTP）等扩展应用
- **电话助手**：电脑端发起呼叫、手机端自动拨号、通话录音回传管理、手机回拨电脑端实时弹窗提醒（插件 `call`）

## 系统要求

### 服务器环境

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | 不限 | Linux（类 UNIX） |
| Web 服务器 | Apache / Nginx / IIS | Nginx |
| PHP | **8.0.2** | **8.2.x 及以上** |
| MySQL | 5.7+ | 5.7 / 8.0（支持 utf8mb4） |
| 附件上传 | 开启 file_uploads | upload_max_filesize > 2M |

### 必需的 PHP 扩展

安装向导（`install.php` 第一步）会自动检测以下扩展，缺一不可：

- `PDO`、`PDO_MySQL` —— 数据库驱动
- `CURL` —— 微信/短信等第三方接口调用
- `GD`（含 FreeType） —— 验证码、图片处理
- `MBstring` —— 多字节字符串处理
- `fileinfo` —— 文件上传类型识别
- `fsockopen` —— 邮件发送等 Socket 通信
- `session` —— 后台登录会话

### 目录权限

以下目录必须**可读写**（Linux 下建议 `chmod -R 755`，属主为 Web 运行用户）：

```
config/          # 安装时写入数据库配置和 install.lock
runtime/         # 框架运行时缓存、日志
public/upload/   # 附件上传目录
```

## 安装步骤

### 1. 获取代码

```bash
# 方式一：Git 克隆
git clone <仓库地址> fhxcrm
cd crm

# 方式二：下载源码压缩包后解压到站点目录
```

### 2. 安装 Composer 依赖

> 如果源码包中已包含 `vendor/` 目录，可跳过此步。

```bash
composer install
```

国内网络建议先配置镜像：

```bash
composer config -g repo.packagist composer https://mirrors.aliyun.com/composer/
```

### 3. 配置 Web 站点

系统支持两种部署方式：
**方式一（推荐）：站点根目录指向 `public/` 目录**

更安全的部署方式，源码不暴露在 Web 目录下。


**方式二：站点根目录指向项目根目录**

直接将域名指向项目根目录，通过根目录下的 `admin.php`、`api.php`、`install.php` 入口访问（入口文件内 `IS_ROOT_ACCESS = true`）。


**配置伪静态**（项目已提供参考配置文件）：

- Apache：参考 `public/htaccess-apache`（重命名为 `.htaccess`）
- Nginx：参考 `public/htaccess-nginx` / `public/nginx.htaccess`
- IIS：参考 `public/htaccess-iis`

Nginx 典型配置示例：

```nginx
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=$1 last;
    }
}
```

### 4. 运行安装向导

浏览器访问：

```
http://你的域名/install.php
```

安装向导共 3 步：

1. **检测环境**：自动检测 PHP 版本、必需扩展、上传限制、目录读写权限，全部通过后点击"下一步"；
2. **创建数据**：填写数据库信息、网站配置、创始人（管理员）信息，见下方[数据库配置说明](#数据库配置说明)；
3. **完成安装**：系统自动导入数据表并生成 `config/install.lock` 锁定文件，同时为当前站点自动生成一个独立的 JWT 签名密钥并写入 `.env` 的 `APP_KEY`（用于移动端 API 的 Token 签发/验证，确保每个部署密钥唯一）。

### 5. 安装完成后的必做事项（重要）

安装完成页面（step5）明确提示以下安全操作：

1. **删除安装程序**：删除 `app/install/` 文件夹和根目录（及 `public/` 下）的 `install.php` 文件；
2. **备份数据库配置**：备份 `config/database.php` 文件，以防丢失；
3. **重命名后台入口**：将 `admin.php` 重命名（详见[后台访问方式与安全建议](#后台访问方式与安全建议)）。

### 6. 登录后台

访问 `http://你的域名/admin.php`（或重命名后的入口），使用安装时设置的创始人账号密码登录。

## 数据库配置说明

安装向导第二步（创建数据）需填写以下信息：

### 数据库信息

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 数据库服务器 | `127.0.0.1` | 数据库服务器地址，一般为 127.0.0.1 或 localhost |
| 数据库端口 | `3306` | MySQL 服务端口 |
| 数据库用户名 | `root` | 具备建表权限的 MySQL 账号 |
| 数据库密码 | - | 失焦时自动测试连接是否成功 |
| 数据库名 | - | 建议小写字母；**需提前创建好空数据库**，向导会检测库中是否已存在数据 |
| 数据库表前缀 | `ymwl_` | 建议使用默认值；同一数据库安装多套系统时需修改 |
| 数据库编码 | `utf8mb4` | 虚拟主机不支持 utf8mb4 时可选择 utf8 |

### 网站配置

| 配置项 | 说明 |
|--------|------|
| 网站名称 | 默认读取 `config/version.php` 中的系统名称，可自行修改 |
| 网站简称 | 后台标题显示用，默认"后台管理" |

### 创始人信息

| 配置项 | 说明 |
|--------|------|
| 管理员帐号 | 默认 `admin`，拥有后台全部管理权限 |
| 密码 | 长度不低于 6 位、不超过 32 位，需二次确认 |
| Email | 管理员邮箱，必填 |

安装成功后，数据库连接信息写入 `config/database.php`。如需手动修改数据库连接（如迁移服务器），直接编辑该文件即可。

> 注意：`config/version.php` 保存系统版本号信息，用于自动升级功能，**请勿手动修改**。

## 后台访问方式与安全建议

### 访问方式

- 默认后台地址：`http://你的域名/admin.php`
- 移动端 API 地址：`http://你的域名/api.php`（供 uni-app 手机端调用）

### 安全建议

1. **重命名后台入口文件**（强烈建议）

   将 `admin.php` 重命名为难以猜测的文件名，例如 `mycrm2026.php`，重命名后的后台访问地址即为：

   ```
   http://你的域名/mycrm2026.php
   ```

   > 若站点根目录指向 `public/`，则重命名 `public/admin.php`；指向项目根目录则重命名根目录的 `admin.php`。

2. **删除安装程序**：安装完成后务必删除 `app/install/` 目录和 `install.php`，防止被恶意重装；
3. **保护敏感文件**：`.env`（包含 JWT 密钥 `APP_KEY`）、`config/database.php` 严禁泄露，`.gitignore` 已默认排除 `.env`；
4. **生产环境关闭调试**：确认 `.env` 中未开启调试模式，`config/app.php` 中开发模式相关配置（`IS_DEV`）保持关闭；
5. **定期备份**：定期备份数据库和 `public/upload/` 附件目录；
6. **HTTPS 部署**：生产环境建议配置 SSL 证书，全站 HTTPS 访问。

## 常见问题

### 1. 访问 install.php 提示"网站已经安装"

系统检测到 `config/install.lock` 文件存在。如确需重新安装，删除该文件后再访问（重装会清空原有配置，请先备份数据库）。

### 2. 安装时提示"目录 config 无法写入"

`config/` 目录没有写权限。Linux 下执行：

```bash
chown -R www:www config runtime public/upload
chmod -R 755 config runtime public/upload
```

（`www` 替换为实际的 Web 运行用户，如 `www-data`、`nginx`）

### 3. 环境检测某扩展显示"未开启"

编辑 `php.ini` 启用对应扩展（如 `extension=fileinfo`、`extension=gd`），重启 PHP-FPM/Apache 后点击"重新检测"。宝塔面板用户可在【软件商店 → PHP 设置 → 安装扩展】中一键安装。

### 4. 填写数据库信息时提示"配置的数据库存在数据"

目标数据库中已存在数据表。请更换一个空数据库，或清空原数据库后重试；同库共存多套系统时请修改表前缀。

### 5. 后台页面样式错乱或接口 404

伪静态未配置或未生效。请按照 `public/` 目录下对应服务器的 `htaccess-*` 参考文件配置 URL 重写规则。

### 6. 上传附件失败

- 检查 `php.ini` 中 `upload_max_filesize`、`post_max_size` 是否过小（建议 ≥ 20M）；
- 检查 `public/upload/` 目录是否可写；
- Nginx 用户还需检查 `client_max_body_size` 配置。

### 7. 修改了自定义字段/权限后页面未更新

系统对字段配置和权限规则做了缓存，执行以下命令清除缓存：

```bash
php think clear
```

或在后台点击右上角清除图标。
